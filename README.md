# Orbus — simulador orbital 2D
Este simulador orbital en 2D (por ahora), es un playground para mí, ir probando cosas de física e ir jugando también con la parte de videojuego.

## Compilar          ← los 3 comandos cmake + requisito MSYS2/raylib
    
## Controles         ← WASD/flechas rotar+empuje, rueda = zoom

## Física            ← 3-4 líneas: N-cuerpos, Verlet, paso fijo, softening Plummer

## Estructura        ← mini árbol src/include con una línea por archivo
